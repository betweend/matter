# Matter Server add-on

Локальный Matter Server с опциональным обходом ошибки device attestation:

- [Matter Server (attestation opt-in)](./matter_server_noattest/)

Добавьте URL этого репозитория в Home Assistant: **Settings → Add-ons → Add-on
store → ⋮ → Repositories**. Описание установки и предупреждения безопасности
находятся в [DOCS.md](./matter_server_noattest/DOCS.md).
