# Matter Server add-on

Отдельный (не официальный) Matter Server с опциональным обходом ошибки device
attestation:

- [Matter Server (attestation opt-in)](./matter_server_noattest/)

Добавьте URL этого репозитория в Home Assistant: **Settings → Add-ons → Add-on
store → ⋮ → Repositories**. Устанавливается рядом с официальным Matter Server
9.2.0; интеграцию Matter нужно вручную переключить на порт **5581**. Описание
установки и предупреждения безопасности: [DOCS.md](./matter_server_noattest/DOCS.md).
